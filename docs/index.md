KuroDocs（暗黑文档）是由我个人搭建和维护的公开在线文档，包含的内容为我本人在涉猎的各个领域（主要是ACGN方向）整理的内容，供需要的观众进行查阅和参考。

KuroDocs 基于 [MkDocs](https://github.com/mkdocs/mkdocs) 部署。你可以访问 KuroDocs 的 [GitHub 页面](https://github.com/FoliAge-0x76/KuroDocs)。
