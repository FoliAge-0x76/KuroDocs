# 魔法具现化

**魔法具现化**不是一个固定势力，而是各种获得了具体形象的魔法的总称。他们的所属各不相同，通常跟随所效力的主人。

同属性的魔法通常在设定上有亲缘关系，而且很自然地，高阶魔法比低阶魔法要强大。年龄设定上，一般Ⅰ魔法的年龄为 8~10 岁、Ⅱ魔法为 14~16 岁，Ⅲ魔法为 18+。

部分魔法具现化有多种不同流行的形象设定，在此一并列出。
