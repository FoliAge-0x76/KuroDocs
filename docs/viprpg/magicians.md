# 魔术师协会
从时空彼岸穿越而来的魔导士们在如果大陆上结成的协会。

魔术师协会的魔导士几乎都从魔法学院出身，大多以尖角巫师帽和法袍的装束出场。

魔术师协会在 2017 结成。创立之初几年里一直被归为「其他势力」，但随着校仓等角色的人气攀升，逐渐获得了与其他较大势力同等的地位。
