# 魔王军
魔王军指的是以[魔王](maou)统领的，由人类与魔族组成的势力。

最初的设计是反派势力，但是做过的坏事最多就是偷走国王的薯片而已，如今主要反派的地位已经转移到[奈伊军](../knigh)。魔王军的成员作为主角出场的作品也相当的多。
