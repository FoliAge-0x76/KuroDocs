# 王国军
王国军指的是以[亚历克斯](alex)为代表的，隶属于薯片王国的势力。

**薯片王国**，又名 [RTP](../terms) 王国，主要由 RTP2000 和 RTP2003 的默认角色及其派生角色组成，是 VIPRPG 的最主要势力之一。

RTP XP/VX/MV 的角色一般不包含在其中，被视为其他大陆的居民。
