# 舞萌 DX 自制谱教程

## 工具

目前比较流行的制谱工具有：

- [Majdata View&Edit](https://github.com/LingFeng-bbben/MajdataView)，此工具自 2025 年 2 月停止更新，支持 PRiSM 版本前的所有语法。
- [Majdata View&Edit X](https://github.com/re-poem/MajdataViewX)，次世代制谱器，支持经过扩展的 [MajSimai](https://docs.majdata.net/majsimai/) 语法。
- [Majdata View&Edit Alpha](https://github.com/Jian04/MajdataViewAlpha)，加入了大量实验性功能的 Majdata V&E 改版。
- Visual Maimai，提供高度可视化的制谱器。

## 创建谱面

一张谱面至少需要包含音乐、封面和谱面文件。以 Majdata 为例，也就是需要三个文件：`track.mp3`、`bg.jpg/bg/png`，以及 `maidata.txt` 。如果你想加上视频背景，也可以加入 `pv.mp4` 。

启动 MajEdit ，选择 `文件 - 新建` ，选中你准备好的 `track.mp3` 进行谱面初始化。

选择 `编辑 - 谱面信息` ，完善谱面信息内容。点 OK 保存。

在 MajEdit 左侧可以选择当前谱面的难度。默认是 EASY，在写谱之前请确认谱面的难度。

新谱面需要先确定 BPM 和偏移。BPM 的写法是在右侧谱面文件编辑器中以圆括号+数字的形式给出，例如 `(220)`。如果不知道曲子的具体 BPM，你可以先定一个大致的数，然后写一长串 4 分音，根据听感进行微调直到四分音能够完全对上拍子即可（也就是节拍器的原理）。

## Simai 语言

Simai 是 Simulator of Maimai 的缩写，用于在各类制谱器中对舞萌 DX 的实际效果进行模拟。MajEdit 及其改版使用 Simai 进行制谱。

我们基于几个例子讲解 Simai。这是 sølips 紫谱的 tap touch taptap touch 段（经典回顾）。

```
(199)
{8}
7v8[8:1],,E5/B5,,2v1[8:1],2,E5/B4,,
E7,E6,E5/8,E4,E3/7h[4:1],E2,Ch[2:3],,
8,8-6[8:1],,8-2[8:1],,8,,3,
3-8[8:1],,,,1,1,1/8,,
```

`(199)` 是 BPM，`{8}` 意为后面是 8 分音。用一个半角逗号代表经过一个音的时值。

单独一个数字构成 Tap，比如这里的 `2`。字母+数字构成 Touch，比如这里的 `E6`。多押用斜杠分隔，比如这里的 `1/8`。

在 Tap/Touch 后增加字母 h 和时值构成对应的 Hold 变种。时值使用 `[分母:分子]` 的格式表示，比如 `7h[4:1]` 意为 7 号键 Hold 持续 1/4 小节（也就是一个 4 分音的长度）。时值也可以用 `[BPM#分母:分子]` 的格式，这样它就获得了一个独立的 BPM，可以在不改动整体 BPM 的情况下实现星星的特殊延迟启动。

使用 起点+形状+终点+时值 的语法来写星星。例如 `7v8[8:1]` 就是从 7 号键出发折线过 C 区到 8 号键的，时长为一个 8 分音的星星。星星的形状有这么几种：

```
x-y # 直线星星
x<y x>y # A 区圆星星
xvy # 过 C 区折线星星
xpy xqy # 绕 C 区弯星星
xppy xqqy # 绕 B 区弯星星
xzy xsy # 闪电星星（x 与 y 必须在对面）
xwy # Wifi 星星（x 与 y 必须在对面）
wVxy # 过 A 区折线星星（从 w 号键到 x 号键再到 y 号键，w 和 x 之间必须间隔 1 个键）
```

接下来一段学习更多的语法。这是神威紫谱的尾杀：

```
{16}
7bx,5,7,5,7,5,8,5,8,5,8,5,1,5,1,5,1,5,2,5,2,5,2,5,
{32}
3b,2,1,8,7,6,5,4,
{4}
3-7b[8:1],
{32}
1bhx[1:4]/3bxs7>1z5[4:11],Cf,
```

在 Tap 后面加字母 b 表示绝赞，加 x 表示 EX Note 。它们和 h 可以叠加，比如 `1bhx[1:4]` 就是一个绝赞 EX Hold，字母的顺序不会影响效果。星星的起点也属于 Tap ，因此也支持绝赞和 EX。

在 Touch 后面增加字母 f 表示烟花 Touch，比如 `Cf`。这也可以和 h 叠加。

在星星的终点末尾追加 b 来代表绝赞星星，比如 `3-7b[8:1]`。

使用 起点+形状+中间点1+形状+中间点2+…+形状+终点 的格式，使用多段形状拼接出一条复杂的星星。比如 `3bxs7>1z5[4:11]` 。

同时同头启动的星星使用星号来分割多条不同的星星，比如 `1-4[8:1]*-6[8:1]` 代表两条同时从 1 号键出发，分别到 4/6 号键的两条直线星星。这在上面的例子里没有提到。
