# Steam 创意工坊项目

本页面整理了 KuroLeaf 的 Steam 创意工坊项目。

## Noita 模组
#### Draw&Guess Art Collection

- [创意工坊链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3617572790)

由Noita你画我猜QQ群（733758650）群友创作的作品，经过调整后替换游戏中的实际贴图。

#### Worse Chinese Translation 更差的中文

- [创意工坊链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3641192557)

经过谷歌多语言翻译20次的中文。致力于更抽象的游戏体验。

#### Lucky Propane 幸运丙烷罐

- [创意工坊链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3681848994)

丙烷罐爆炸时触发随机事件。

此模组曾登上创意工坊周热门榜榜首。

#### Better Kicks 更好的踢击

- [创意工坊链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3655534396)

对踢击的各项性能进行了优化，并提供可调节的设置选项。

#### 参与制作的模组

- [猫娘的混沌魔典](https://steamcommunity.com/sharedfiles/filedetails/?id=3619737665) - 参与部分美术工作
